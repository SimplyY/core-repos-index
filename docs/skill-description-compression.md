# Skill 描述压缩规范

这份规范用于批量把完整 `SKILL.md` 描述压缩成群置顶卡片中的一句中文说明。压缩由模型在离线维护阶段完成；运行时代码只读取已生成结果，不自行改写语义。

## 输入

- Skill 名称与完整中文/英文描述。
- Skill 的触发场景、主要动作、主要对象、输出结果和硬边界。

## 输出

只输出一句完整中文说明，优先回答“这个 Skill 具体帮用户完成什么”。按频率档位控制长度：低频最多 20 字、中频最多 30 字、高频最多 40 字；目标分别超过 5、10、20 字。需要跨档复用时，为不同档位分别生成 `description_zh_low`、`description_zh_medium`、`description_zh_high`，避免频率变化后拿高档长句硬塞进低档。原文不足时保留原文能支持的最长完整语义，不补造事实。

压缩优先保留：

1. 核心动作 + 核心对象；
2. 关键结果或落点（例如写入 Base、生成报告、发送卡片）；
3. 会改变用户预期的安全边界（例如只读、不提供交易建议、需确认后写入）。

删除触发词堆叠、示例列表、实现细节和重复修饰。不得把引号中的示例动作当作 Skill 的能力，也不得把“不生成 / 不提供 / 不允许”等否定语句改写成正向能力。

## 维护约束

一次处理当前所有可访问注册群的去重 Skill。每条结果必须记录源描述哈希；源 `SKILL.md` 描述变化后必须重新生成对应摘要，禁止静默沿用旧摘要。没有可验证摘要时，`apply` 必须停止。
